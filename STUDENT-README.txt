NEUEWAVE MARK GENERATOR
A quick guide for students
==========================

WHAT IT IS
A design tool that runs in your web browser. You build versions of the
neuewave mark from text and four elements (earth, fire, water, wind),
then save or export the ones you like.


HOW TO OPEN IT
1. Unzip this folder.
2. Double-click "neuewave-mark-generator.html".
   It opens in your browser. No install and no internet needed.

Use Google Chrome or Microsoft Edge on a laptop or desktop for the best
results. Safari and Firefox also work.


THE SCREEN
- Left:   the canvas, which shows your design.
- Right:  the control panel. Click a heading to open or close a section.

On the canvas you can:
- Drag an element or the text to move it.
- Hold Shift and drag an element to rotate it.
- Scroll over an element to resize it.


A FIRST TEN MINUTES
1. Click a few PRESETS at the top of the panel to see what is possible.
2. Open STYLE. This changes the look of all four elements together:
   3D or 2D, Solid / Line art / Wire, Smooth or Faceted, and the finish.
3. Open one element, for example FIRE:
   - Solid:       choose the starting shape (sphere, cube, torus...).
   - Supershape:  raise Amount, then move the sliders, or press Randomise.
   - Deform:      stretch, taper, twist, bend.
   - Array:       how many copies, and how they are arranged.
4. Open WORDMARK and type your own text. Try Shuffle for quick ideas.
5. Press "New seed" to get a different random arrangement.


SAVING YOUR WORK
- COLLECTION (top of the panel): type a name and press Save.
  Your design is stored with a small picture. Click it later to reload it.
- "Compare all" shows everything you saved side by side.
- "Export file" saves your whole collection as one file.
  Do this before you change computer or browser, and to hand work in.
  "Import file" loads it back.

Important: the collection is kept inside the browser you are using.
If you clear your browsing data, or switch browser, it is gone unless
you exported it first.


EXPORTING
- Export PNG:  a picture. Choose the size first (1080, 2160 or 4096).
- Export SVG:  vector artwork you can open in Illustrator or Figma.
- Record:      an animation as GIF, MP4, WebM, or a folder of PNG frames.


MAKING IT MOVE
- "Play motion" (in Export) plays the built-in movement.
- PHYSICS > Simulate > Run lets gravity, wind and collisions act on the
  elements.
    Kick   gives everything a push.
    Hold   freezes the moment so you can export it.
    Reset  puts everything back.
  With physics running, press on an empty part of the canvas to push the
  elements around.


IF SOMETHING GOES WRONG
- It runs slowly: lower "Resolution" in Style, use fewer Copies, or turn
  off an element with Show > Off.
- An element has vanished: check Show is On, then click a preset to
  start again from a known state.
- The file does not download: allow downloads for this page in your
  browser.
- You want a clean start: click the "Elements" preset.


GOOD TO KNOW
- The text is set in Monument Extended, the neuewave typeface. Please
  use this tool for coursework only and do not share it outside class.
- The "source" folder holds the code behind the tool. You do not need it
  to use the tool; it is there if you are curious or want to change it
  (see source/README.md).
